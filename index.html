Frequently Asked Questions (FAQ)

How to view 3D STL files online without installing software?

Simply drag and drop your .stl file onto the web page, or click the 'Open STL File' button to select a local file. The model will be rendered instantly using WebGL.

How to switch to CAD Technical Edge rendering mode?

Select 'CAD Technical Edges' in the Render Mode dropdown on the left panel, and set Background Style to 'Pure Light' to view crisp engineering outlines.
